# Layout, Grids & Visual Hierarchy

> Treat graphic design as intentional communication by using layout, grid systems, alignment, spacing, scale, and focal points to guide the viewer in a deliberate order.

## Learning objectives

- Explain Layout in your own words.
- Apply Grid system to a realistic classroom or community example.
- Complete the practice task and reflect on one improvement.

## Lesson notes

### 1. Layout

The planned arrangement of text, images, and empty space that determines how a viewer moves through information.

### 2. Grid system

An invisible set of columns, rows, or baselines that creates alignment, rhythm, and consistency across a design.

### 3. Visual hierarchy

The order of attention created through scale, contrast, spacing, position, and grouping so important content is seen first.

## Guided practice

Rebuild a crowded poster on paper or in Canva using one grid, one focal point, aligned edges, and deliberate empty space. Ask a partner to name the first three things they notice.

Work in pairs when devices are shared. Write your prediction before using a device, then compare the result with what actually happened.
